A hands-on guide to **data manipulation and analysis** with Pandas. Learn core operations through practical examples.

---

## 📚 Topics Covered

### **Data Structures**
- **Series**: 1D labeled arrays
- **DataFrame**: 2D tabular data
- **Indexing**: `.loc[]`, `.iloc[]`, boolean indexing

### **Data Input/Output**
- Reading/writing CSV, Excel, JSON files
- Handling missing values (`dropna`, `fillna`)
- Data type conversions (`astype`)

### **Data Manipulation**
- Filtering rows/columns
- Sorting and ranking
- GroupBy operations (`groupby`, `agg`)
- Merging/joining DataFrames (`merge`, `join`)

### **Data Analysis**
- Descriptive statistics (`describe`, `value_counts`)
- DateTime operations
- Pivot tables and crosstabs
- Basic visualization (integration with Matplotlib/Seaborn)
