# 📊 Data Visualization with Matplotlib & Seaborn

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue)](https://python.org)
[![Matplotlib](https://img.shields.io/badge/Matplotlib-3.5%2B-orange)](https://matplotlib.org)

A collection of **data visualization** examples and templates using Matplotlib and Seaborn.  
Perfect for exploratory data analysis (EDA), reports, and dashboards.

---

## 🚀 Features
- **Matplotlib**: Customizable plots (line, bar, scatter, histograms).  
- **Seaborn**: Statistical visualizations (heatmaps, pairplots, distribution plots).  
- **Themes**: Prebuilt styles (`ggplot`, `darkgrid`, `whitegrid`).  
- **Export**: Save plots as PNG/SVG/PDF for publications.
